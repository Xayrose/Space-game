# Космический сборщик

3D browser game + interactive project showcase.

## Structure
- `index.html` — animated project website.
- `game/index.html` — playable game build.
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow.

## Stack
HTML5, CSS3, JavaScript ES6, Three.js r140, WebGL, Web Audio API.

## Controls
WASD / Arrow Keys on desktop. Touch joystick + BOOST on mobile.

## Game
Crystals, meteorites, sectors, lives, TURBO / SHIELD / MAGNET buffs, particles and adaptive mobile UI.

The visual direction follows open anti-template principles from Taste Skill: intentional typography, asymmetric composition, restrained density and motion-led interaction.
