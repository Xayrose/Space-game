# Space - Game

Одностраничный React + Three.js сайт для игры **Space - Game**.

## Что внутри

- React + Vite
- React Three Fiber
- Three.js
- Tailwind CSS
- GSAP + ScrollTrigger
- 8 планет с 2K-текстурами
- Солнце как источник света
- орбитальные линии
- звёздное поле
- Bloom + Vignette
- LOD через Drei Detailed
- mouse parallax
- адаптивная верстка PC / Android
- отдельная браузерная игра в `game/index.html`

## Игра

Кнопка **PLAY IN BROWSER** открывает игру прямо в браузере.

Кнопка **DOWNLOAD GAME** позволяет сохранить HTML-файл игры отдельно.

## Запуск сайта локально

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
```
